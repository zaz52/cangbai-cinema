TVBox 配置库 10

你提供的 10 个配置地址已预置。可逐个检测、预览兼容接口，再选择导入到上面的点播源列表。

配置地址 ≠ 搜索 API ≠ 可播放影片。扩展名为 JPG/PNG/WebP 的配置，只有响应内容是 JSON 才能直接解析。多仓、Spider、加密规则需对应专用引擎，本站不会执行第三方代码。含 HTTP 的旧配置地址仅用于管理员识别，不能直接成为 HTTPS 播放源。

源目录不等于播放许可
